# PosManagementSystem

A Point of Sale (POS) management system for handling sales, products, inventory, customers, and sales reports.

## Features
- Product and category management
- Sales and billing
- Inventory tracking
- Customer management
- Sales reports

## Tech Stack
- Frontend: client (npm)
- Backend: server (Node.js)

## Installation

1. Clone the repository:
   git clone https://github.com/username/PosManagementSystem.git
   cd PosManagementSystem

2. Install dependencies:
   cd server
   npm install
   cd ../client
   npm install

## Running the Project

Open **two terminals**.

Terminal 1 (server):
   cd server
   npm run dev

Terminal 2 (client):
   cd client
   npm run dev
